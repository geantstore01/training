# ÉDUCAPILOTE — application web

Next.js App Router, React, TypeScript strict, Tailwind et composants shadcn/ui.

Guide de déploiement, architecture et limites : [modules 9 et 10](../../docs/module910.md).

`npm ci`, puis `npm run typecheck`, `npm test` et `npm run build`.

Les données de `tests/browser/backend.mjs` sont des doubles de recette explicites. Le frontend de production utilise exclusivement les microservices.
